# Changelog

## [1.1] - (02.09.2026)

### Added

- Upgrade to LSM6DSV16BX IMU and MAXM86161 PPG sensor
- Added support for WULPUS-Pro shield, and BGT60TR13C mmWave radar
- Comprehensive firmware documentation.

### Changed

- Refactored the nRF5340 firmware into modular AFE, BLE, BSP, core, and sensor components.
- Added runtime ADS1298 configuration, unified packet framing, and shared-SPI arbitration.
- Updated the mainboard, debug board, ExG/EMG shields, and template shield.
